# Frontend (Angular) — Ticket Booking

This folder contains a minimal Angular app scaffold to run the sample booking component.

Quick start:

1. Install dependencies:

```bash
cd frontend
npm install
```

2. Run the backend (Spring Boot) on port 8080 from the `backend` folder.

3. Start the frontend dev server (proxies `/api` to backend):

```bash
npm start
```

The app will be available at http://localhost:4200.
